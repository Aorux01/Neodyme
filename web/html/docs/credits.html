How to Contribute

Contributions of all kinds are welcome: code, documentation, translations, and testing.

GitHub Repository

Fork the repo, make your changes, and open a pull request.

Issues Tab

Browse open issues and pick up a task labeled "good first issue".

Discord Community

Join the conversation, ask questions, and coordinate work.

Submit a Bug or Feature Request

Found a problem or have an idea? Help us improve Neodyme by reporting it on the issue tracker.

Reporting a Bug

  1. Open the Issues tab and search for existing reports first.
  2. Click New Issue and choose the Bug Report template.
  3. Include your Neodyme version, steps to reproduce, expected vs. actual behavior, and relevant logs from the logs/ directory.
  4. Attach screenshots or console output when possible.

Requesting a Feature

  1. Open a New Issue using the Feature Request template.
  2. Describe the problem your feature solves and the proposed behavior.
  3. Add the enhancement label so maintainers can triage it.
For quick questions or discussion before opening an issue, reach out on the Discord community.
